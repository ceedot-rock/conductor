# DEMO.md — the 5-minute video walkthrough, shot by shot

Total budget: ~5 minutes. Every shot below is reproducible from this repo:
`npm install && npm test && npm run dev`, then `npm run seed` in another
terminal. Nothing is faked; the CuNi outputs are compiler-generated.

## Setup (before recording)

1. `npm run dev` → Worker at http://localhost:8787 (panel loads, demo-shop repo seeded).
2. `npm run seed` → 3 tasks created, 2 agent pushes simulated, real CuNi
   example generated into the panel.

## Shot list

### 0:00–0:30 — The problem (you, to camera)
"GitHub was built for humans typing git commands. But the next generation
of software is written by agents — hundreds of them, on the same codebase,
at the same time. The question Cloudflare asked is: what does the git
platform look like when the human never touches git? This is our answer."

### 0:30–1:10 — Shot 1: speak an intent, agents fan out
- Panel open on the control-panel tab.
- Type in the intent box: *"Add a 0.5% fee to every order total"*
- Click **Dispatch agents**.
- The task appears in the feed: status `open`, branch `agent/t-…`.
- Say: "No branches to create, no remotes to add. One sentence became a
  workspace. The agent is already working."

### 1:10–2:10 — Shot 2: the review lands, one-tap merge
- Click the task. The simulated agent push has run the review pass.
- Show: diff of `src/orders.py` (the fee implementation), review summary
  ("1 file changed, heuristic findings"), findings list.
- Click **Approve & merge → main**. Status flips to `merged`.
- Say: "Every push gets an automatic review before a human ever sees it.
  The decision is one tap — approve or reject. That's the whole UI."

### 2:10–2:50 — Shot 3: the review catches something
- Click the second task (*"Wire up the payments client"*).
- Show the review: **block — possible secret committed**.
- Click **Reject**.
- Say: "The agent committed an API key. The review caught it, blocked the
  merge, and the rejection took one click. This is the coordination layer
  agents need — and the one humans can actually supervise."

### 2:50–4:10 — Shot 4: the CuNi differentiator
- Switch to the **CuNi exactness** tab.
- Show the CuNi source (`examples/fee.cuni` — the 0.5% fee).
- Show the verdict: **EXACT — 2 seats, byte-identical stdout**.
- Scroll the emitted Python and the emitted JavaScript side by side;
  show the identical stdout (`0.5`, `0.0499`, `12.5`).
- Say: "Here's what no other entrant has. CuNi turns one program into any
  programming language — 144 of them — and proves the outputs are
  byte-identical everywhere, or it refuses to emit at all. I speak an
  intent, agents write the code, and CuNi guarantees it behaves exactly
  the same in every language. This output was generated by the real
  compiler, not a mock."

### 4:10–4:50 — Shot 5: under the hood (one architecture slide or terminal)
- Show the README architecture diagram (or `src/` listing).
- "Cloudflare Workers serve the API and the panel. Artifacts is the
  versioned filesystem — every task forks the repo through the Artifacts
  binding, agents push with git, and push events trigger reviews. The only
  Cloudflare-coupled layer is the storage binding; everything else is
  plain TypeScript."

### 4:50–5:00 — Close (you, to camera)
"Conductor: you speak, agents do the git. Code, demo, and docs are linked
below — Apache-2.0, try it yourself."

## If something goes wrong live

- Panel shows "API unreachable": `npm run dev` isn't running. Start it.
- CuNi tab says "not seeded": run `npm run seed`.
- Anything else: `npm test` re-verifies the whole backend in under a second.
